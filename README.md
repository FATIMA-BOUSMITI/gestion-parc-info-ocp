# Gestion Parc Informatique

This project is a web application for managing IT assets and support tickets in a company environment.

## Objective

The main goal is to centralize support requests, assign issues to technicians, and monitor machine status and repairs efficiently.

## Features

- user and technician authentication
- ticket submission by users
- ticket assignment to technicians
- technician dashboard
- machine status updates
- resolution and closure of incidents
- monitoring of outages and support workflows

## Technologies

- PHP
- MySQL
- JavaScript
- Bootstrap
- Tailwind CSS
- XAMPP

## Main modules

- login and authentication
- user dashboard
- technician dashboard
- ticket management
- incident handling
- machine monitoring

## Setup

1. Start Apache and MySQL in XAMPP.
2. Place the project inside the htdocs folder.
3. Import the database if needed.
4. Open the project in the browser.

## Notes

This project demonstrates a practical IT support workflow with a focus on incident tracking, technician assignment, and asset maintenance management.
